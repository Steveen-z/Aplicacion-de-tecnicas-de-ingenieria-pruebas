# Evaluación breve ISO/IEC 25010

| Característica | Evaluación | Evidencia / pendiente |
|---|---|---|
| Adecuación funcional | Alta: P01–P12 implementados con reglas de negocio (estados, requisitos de rol, comparación 2–4) | Endpoints en README; pruebas unitarias |
| Eficiencia de desempeño | Aceptable para prototipo: paginación, índices del script SQL, consultas por Prisma | Sin pruebas de carga |
| Compatibilidad | API REST JSON, CORS configurable, OpenAPI/Swagger | |
| Usabilidad | Limitada al ser solo API; errores con mensajes claros en español; Swagger para explorar | La interfaz final es el frontend |
| Fiabilidad | Transacciones en cambio de precio y revisión de documentos; filtro global de errores | Notificaciones de baja de precio no atómicas |
| Seguridad | bcrypt, JWT revocable, roles, throttling, helmet, validación estricta, archivos por firma, ubicación aproximada, documentos privados | Sin auditoría externa; DUI sin dígito verificador |
| Mantenibilidad | Alta: capas, puertos/adaptadores, casos de uso pequeños, dominio testeable sin framework | Cobertura de pruebas aún baja (solo dominio) |
| Portabilidad | Docker Compose para BD; configuración por variables de entorno; almacenamiento intercambiable | Disco local para archivos |
